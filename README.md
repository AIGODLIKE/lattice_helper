Lattice modifiers can be added quickly, and lattice control can be added by selecting a block in edit mode.
![Image](https://github.com/user-attachments/assets/e67b5e87-62c1-4fcb-9b59-6b409c7c1d76)

Install  
![Image](https://github.com/user-attachments/assets/d3c1ad5f-9a38-4dcd-977d-dedadcbd2c4c)

Usage  
3DView -> Context Menu -> LatticeHelper
  
Entirety  
All selected objects as a single entity
![Image](https://github.com/user-attachments/assets/725aa0a8-f547-4e86-8a81-95db66aa385c)

Bounding Box  
Use the bounding box of each selected object as a separate lattice
![Image](https://github.com/user-attachments/assets/ef8c0509-5d81-47b0-b064-5b179c4ec8ff)

Selection Block (Edit Mode)  
Add a lattice for each selected block as a separate region within edit mode
![Image](https://github.com/user-attachments/assets/0abeed87-9cd3-402f-a9b1-cc97101f0ea9)

Entire Block (Edit Mode)  
Add a lattice for all selected blocks within edit mode as a single region
![Image](https://github.com/user-attachments/assets/0450a883-7f9a-49e5-9132-5259abf9db03)
